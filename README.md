# ✈️ Airline Reservation System

The **Airline Reservation System** is a console-based application developed in **C++** using **Object-Oriented Programming (OOP)** principles. It allows users to manage airline reservations efficiently through a menu-driven interface.

## 📌 Features

* Passenger Registration
* Flight Booking
* Ticket Reservation
* View Available Flights
* Search Passenger Records
* Cancel Reservation
* Display Booking Details
* File Handling for Data Storage
* Menu-Driven Interface

## 🛠️ Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling
* Visual Studio Code / Code::Blocks / Dev-C++
